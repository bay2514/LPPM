# KONTEN DIBUTUHKAN

## 1. Halaman Profil
- **Tentang LPPM:** Teks deskripsi sejarah dan fungsi lembaga.
- **Visi Misi:** Teks resmi visi dan misi.
- **Struktur Organisasi:** Gambar/bagan struktur dan daftar nama pejabat.
- **Kontak:** Alamat fisik, email resmi, nomor telepon, dan link Google Maps.

## 2. Halaman Layanan
- **Penelitian & Pengabdian:** Panduan pengajuan, template proposal, dan alur proses.
- **KKN:** Daftar lokasi, jadwal, dan syarat pendaftaran.
- **E-Jurnal:** Daftar link jurnal internal/eksternal yang dikelola.

## 3. Data Dashboard
- Angka capaian riil untuk tahun 2024-2026 (Penelitian, PKM, Publikasi, HKI).
