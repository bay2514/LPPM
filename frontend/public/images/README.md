# Slot Foto

Tempatkan berkas foto di sini sesuai dengan slot yang tercantum di
`src/shared/config/imageSlots.js`. Contoh: `hero-beranda.webp` untuk hero beranda.

Panduan:
- Gunakan format WebP atau PNG.
- Optimalkan ukuran agar masing-masing berkas < 300 KB.
- Sesuaikan dimensi dengan yang tertera di config.

Saat Anda menambahkan foto, halaman akan langsung memuat berkas tersebut.
Saat tidak ada foto, halaman menampilkan placeholder polos.
